# Hospital Appointment Reminder and Scheduling System

## Problem
Appointments in hospitals are difficult to manage. Patients often forget their scheduled appointments and the hospital sometimes double-books the same time slot for multiple patients. This leads to wasted time, missed care and scheduling conflicts between patients, receptionists and doctors.

## Proposed Solution
The proposed system is a web-based Hospital Appointment Reminder and Scheduling System that lets patients book, reschedule and receive reminders for appointments, while giving receptionists and doctors the tools to manage schedules. It solves the core problems of missed appointments and double-booking by sending automated reminders and confirmation requests, cancelling unconfirmed or missed appointments to free up slots, and checking doctor availability in real time before any booking is confirmed. Key features include registration and login, appointment booking and rescheduling, a doctor's dashboard, and appointment reports, all delivered through Agile iterations so the team can adapt to changing requirements as real users give feedback. The expected outcome is fewer missed appointments, no double-booking, reduced administrative workload, and better visibility into appointment data.

## Users
* **Patients** - book, reschedule, and receive reminders for appointments
* **Receptionists** - manage bookings and prevent scheduling conflicts
* **Doctors** - view schedules and manage availability

## Features
- Patient registration and login
- Book appointment
- View doctor availability
- Automated confirmation request
- Doctor's dashboard
- Appointment reminders
- Automated cancellation logic
- Reschedule appointment
- Appointment reports
- Manage profile
